Migration-time finding (fixed, not hidden)
-------------------------------------------
The first full-package run after the deletion (before this evidence file
was finalized) caught a genuine migration defect, not a mutant-coverage
gap: TestInitiateDeposit_AmbiguousOutcomeCallsQueryStatusBeforeNotCascading
(adversarial_test.go), migrated to the live InitiateDepositAttempt path,
asserted "exactly 1 QueryStatus call" - but InitiateDepositAttempt
(deposit_v2.go) never calls QueryStatus synchronously at all; an ambiguous
outcome is left for the sweeper (the exact QueryStatus-in-tx anti-pattern
ADR 0095 removes, already documented for the callback-path twin of this
test). This was the deleted legacy chain's OWN behaviour, not a
still-live invariant, so migrating it onto the live path as originally
written was wrong. Fixed by deleting the test (redundant once its
replacement exists) and strengthening
TestInitiateDepositAttempt_AmbiguousOutcome_T6 (deposit_v2_integration_
test.go) to assert the strict opposite (zero QueryStatus calls) plus the
unchanged no-cascade/no-ledger-effect guarantees, using spy providers -
never a weaker assertion than the original. Full package re-run after the
fix (below) is green.
