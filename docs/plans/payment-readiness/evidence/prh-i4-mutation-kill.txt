PRH-I4 (ADR 0097, PAYWH-RL-1) mutation-kill evidence
=====================================================

Method: manual, one mutant at a time. For each mutation below, the exact source edit is
made with sed/python3 (anchored, exact-match string replacement), the named test command is
run to confirm it FAILS, the failure output is captured (raw text below and in
/tmp scratchpad mutation-runs/*.txt during the session), and `git checkout -- <file>` restores
the original before the next mutation. Each mutation was independently re-verified to produce
a clean pass after revert. Unlike PRH-REF's prh-ref-mutate.py, this is NOT a committed,
re-runnable harness (time-boxed manual execution) - each mutation's exact diff is recorded
below in unified-diff form so it can be reproduced and re-run.

Environment: shared CI-local PostgreSQL (docs note it may be used by other agents
concurrently - see the isolated TestResolutionIsolation_* wall-clock-threshold flake noted in
commit 1eddcbb's own message, reproduced and confirmed unrelated to this change by re-running
in isolation). Go 1.26.8.
