PRH-I1 (ADR 0095) mutation-kill evidence
=========================================

Scope of this file so far: PRH-I1 step (a) only (migration 0101 -
payment_attempts, payment_provider_events, guard triggers, RLS,
backfill). Steps (b) through (i) are NOT IMPLEMENTED yet; their mutations
(MX1-MX6, MX8-MX15, MX17-MX21, MX24) are out of scope for this file until
those steps land and are appended here.

Harness: a temporary, verified-anchored source substitution directly on
migrations/0101_payment_attempts.up.sql (the migration file itself, since
step (a) is schema/trigger only - there is no compiled Go mutant to build
for these two). Each mutation:
  1. is applied via a Python one-shot `str.replace` on an exact,
     `assert count == 1`-verified anchor string (never a fuzzy/regex
     match, so a mismatch fails loudly instead of silently mutating
     nothing or something else);
  2. is proven present via `grep` for the mutation's own marker comment;
  3. is exercised by running the SPECIFIC test named for it in ADR 0095
     §16.4, against a fresh scratch database (internal/testsupport/
     scratchdb, via TEST_ADMIN_DATABASE_URL - never the shared
     TEST_DATABASE_URL);
  4. the original file is restored byte-for-byte from a pre-mutation copy
     and `git status --porcelain`/`git diff --stat` confirmed clean
     before continuing.

Environment: local PostgreSQL (CI-local container), scratch databases via
internal/testsupport/scratchdb using TEST_ADMIN_DATABASE_URL. Go per
go.mod. Base: worktree branch worktree-agent-a048d85a077316518, on top of
commit 142348f ("feat(payments): PRH-I1 step (a) - migration 0101 payment
attempts state machine").

Result: 2/2 killed (the two step-(a) rows the orchestrator named:
MX22, MX23). MX24 (lock ordering, N1) is orchestrator wiring, not
