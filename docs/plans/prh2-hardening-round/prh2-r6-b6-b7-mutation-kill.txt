Correction of revision 1 (ledger-finance LF-C2)
-----------------------------------------------
Revision 1 classified M5d as "near-equivalent, no test hook can produce a terminal reference-less attempt".
That was wrong: a callback by merchant reference on a reference-less live attempt can reach
ApplyDisputeFromNonTerminal WITHOUT binding a reference (receipt.go tombstone path; the section 28 multiple-
success T10 path). With M5d applied a stale-snapshot processUnreferenced then errors in RescheduleNonTerminal on
the terminal row. The new stale-snapshot test (tombstone shape) kills M5d. M2a/M8c remain equivalent only in
the sense that Escalate's SQL CAS covers them; M2a is now killed because the due check also gates the audit.

Not-observable-by-state note
----------------------------
The ADR 0102 7.7 ordering (escalation last) is not observable through database state for the missing-amount
and nil-reference branches (same rows either way), so it is pinned by a source-order test
(TestEscalationCallIsLastStatementOfItsBranch_ADR0102_7_7), which kills C1b/C1e. The pending branch ordering
IS behavioural (C1a) because a T9 drain can resolve the attempt in the same transaction.
